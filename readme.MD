* Реализовать REST-микросервис лимитов, который имеет следующий функционал:
* Для каждого пользователя в БД хранится текущее значение его лимита (первоначально 100000.00).
* Считается, что лимит может изменяться со временем, дефолтное значение определяется как общее для всех.
* Каждый день в 00:00 лимит для всех пользователей должен сбрасываться до стандартного значения.
* При успешной операции во внешней системе, в рамках которой используется лимит, значение лимита должно уменьшаться на
  соответствующую сумму.
* Если операция по какой-то причине не завершилась успешно, должна быть возможность восстановить ранее списанный лимит.
* Стратегию восстановления выбрать самостоятельно.
* Должна быть предусмотрена возможность резервирования лимита на время проведения операции во внешней системе — до её
  подтверждения или отмены.
* Если при запросе лимита используется идентификатор пользователя, отсутствующий в базе данных, необходимо автоматически
  создать новую запись с дефолтным значением лимита.

### _Технологии:_

**Java 17/21, Spring Boot 3.x.x, PostgreSQL, Liquibase.**
